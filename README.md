# Omar Gamal — Angular Frontend Portfolio

A premium one-page portfolio built with Angular 21 for Omar Gamal Mohamed.

## Highlights
- Animated portfolio intro
- Personal hero with real portrait
- Enterprise-focused experience section
- Selected project case studies
- Responsive layout
- CSS motion + scroll reveal
- Downloadable CV
- No backend required

## Run locally
```bash
npm install
npm start
```

Open: http://localhost:4200

## Production build
```bash
npm run build
```

If deploying to a GitHub Pages project repository, set the correct `--base-href` for the repository name when building.
