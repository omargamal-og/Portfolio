## Getting Started

Clone the repository:

```bash
git clone https://github.com/omargamal-og/Portfolio.git
```

Enter the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Then open:

```text
http://localhost:4200
```

---

## Production Build

Create a production build with:

```bash
npm run build
```
